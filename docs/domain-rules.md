# 领域边界

编排潮俗皮影演出、AI 动画、互动工作坊与非遗授权资源。

领域服务围绕以下边界组织：

- 演绎内容与授权（`src/shadow_play/content.py`）
- 场次和场地（`src/shadow_play/sessions.py`、`resources.py`）
- 工作坊预约与签到（`src/shadow_play/sessions.py`）
- 教具与志愿者（`src/shadow_play/resources.py`）
- 取消、损坏与历史保留（`sessions.py` 的状态机）
- 负责人场次视图（`src/shadow_play/views.py`）

资料版本只能递增。参与方、事实和约束均不能为空，示例不得包含真实个人信息、账号或凭据。

## 核心业务规则

### 演绎内容版本

- 同一内容编号（如 `MULAN-01:3`）下版本号自动递增，新版本默认草稿；
- 只有**已确认**版本能进入公开活动；草稿、撤回版本一律被发布门拦截；
- AI 动画随版本提交来源标注（模型、提示词记录、底本）与适用范围
  （允许的场次类型、起止日期），缺标注不能确认、不能使用；
- AI 标注的适用范围在发布时按本场类型与开场时间再次校验。

### 非遗传承人授权

- 授权生命周期：`pending → granted`，以及 `rejected / expired / revoked`；
- 授权按场次类型与有效期覆盖；未挂授权、待确认、被拒、过期、撤销或
  范围不覆盖时，素材不能进入活动；
- 每次状态变更只追加、不改写，授权历史完整可追溯。

### 场次发布门（PublishBlocked 一次性列出全部缺口）

1. 责任人已指定；
2. 场地时间无冲突（建场时即锁定，半开区间，首尾相接不算冲突）；
3. 每条内容均为已确认版本，且挂接授权覆盖本场类型与开场时间；
4. 每种讲解语言至少有一名具备该语言能力的讲解或工作坊带领者；
   工作坊必须有具备对应资质的带领志愿者；
5. 教具水位满足当前预约人数。

### 预约、签到与现场调整

- 预约即按人数占用教具，容量或窗内教具不足时整笔拒绝（不产生半占用）；
- **签到幂等**：同一预约重复签到返回首次结果（`duplicate=True`），
  不重复释放或占用资源；
- 迟到在时间窗内（开场后、结束前）仍可签到；
- 实际到场少于预约时，当场释放多余教具；
- 工作坊**拆组**把部分人转入另一已发布场次（含临时加场），
  源场次释放、目标场次占用在同一操作内完成；目标容量/教具不足时整体回滚；
- 教具**损坏**立即退出可分配池，受影响的未结束场次按当前实际人数补位，
  补不齐时在 `DamageReport.shortages` 上报缺口，绝不双重分配同一套教具；
- 场次结束时未签到预约记为爽约（`no_show`），记录保留、资源释放。

### 取消与历史保留

- 取消只作用于**未开场**场次；进行中场次不能整体取消；
- 活动级取消逐场处理，返回 `(已取消, 跳过)`，已完成场次不受影响；
- 已完成场次冻结完成快照：内容版本、AI 来源标注、授权状态原样留存；
  事后撤销授权不改变历史快照。

### 负责人视图

`SessionViewBuilder` 一次聚合：内容依据（版本状态/AI 标注/授权明细/可用判定）、
各类教具水位（完好/窗内占用/可占用/本场需求/已配编号）、责任人与排班、
待补授权清单，以及草稿场次的全部发布障碍。
