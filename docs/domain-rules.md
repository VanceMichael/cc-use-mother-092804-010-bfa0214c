# 领域边界

编排潮俗皮影演出、AI 动画、互动工作坊与非遗授权资源。

现有领域资料围绕以下边界组织：

- 演绎内容与授权（`src/shadow_play/content.py`）
- 场次和场地（`src/shadow_play/sessions.py`）
- 工作坊预约与签到（`src/shadow_play/bookings.py`）
- 教具与志愿者（`src/shadow_play/resources.py`）
- 签到与取消（`src/shadow_play/office.py`）

资料版本只能递增。参与方、事实和约束均不能为空，示例不得包含真实个人信息、账号或凭据。

## 规则到实现的落点

### 演绎内容与授权

- 内容版本号严格递增，旧版本不可改写；场次排定时固定 `(内容编号, 版本号, 标题快照)`。
- 授权有"待确认 / 已确认 / 未获许可 / 已过期"四种状态，且有生效与失效日期。
- 公开闸门 `BackOffice.schedule_session` 对每个节目调用 `Program.ensure_publishable`：
  版本必须已确认、当日授权必须有效，否则场次不得创建。
- 版本声明的授权若未登记（未获许可素材），版本无法入库；未登记内容无法被场次引用。
- AI 动画用 `AIGenerated` 标注工具（来源）、提供方与适用范围（公开演出/展陈/
  工作坊/宣传）；缺来源、缺范围或用途超出范围，一律过不了闸门。
- 授权事后被撤销时，未发生场次在总览"待补授权"中暴露；已完成场次按快照保留历史。

### 场次、场地与志愿者

- 场次分公开演出、主题展陈、互动工作坊；工作坊只能排在支持互动的场地。
- 时间重叠的场次不能使用同一场地，也不能重复安排同一名志愿者。
- 志愿者要求包含讲解语言、互动技能与最少人数，排定时即校验资质。

### 教具库存与实际人数

- 教具按个体编号管理（如 `PK-07`），不是只记总数；占用落在具体编号上。
- 场次用 `equipment_plan` 声明需求：固定数量、`"person"`（按实际人数）或
  `"group"`（按拆组数）。
- 任何一次变动（预约、取消、签到、拆组、损坏、修复、加场、场次取消/完成）都
  触发 `_reconcile_resources`：跨时间重叠场次做个体编号互斥，同一套教具绝不
  会被双重分配；需求无法满足时抛 `ResourceConflict` 并在水位中显示"有缺口"。
- 损坏个体立即退出可用池并触发全部未发生场次重算；备用品足够时静默换配。
- 迟到签到标记迟到但不释放资源；确认缺席（`mark_no_show`）才释放名额与教具。

### 预约、签到与取消

- 预约受场地容量约束；预约失败回滚，不留下脏占用。
- 签到结果是带凭证的不可变对象 `CheckIn`，重复签到返回首次原结果（幂等）。
- 已取消的预约不能签到；已完成场次的预约不能取消。
- `cancel_session` 只允许取消未发生场次：释放教具、未签到预约置为已取消；
  已完成演出、签到凭证、内容依据快照与作品授权记录全部保留。

### 负责人总览

`BackOffice.overview(session_id)` 一次性给出：内容依据（版本与 AI 来源/范围）、
资源水位（需要/已分配/库存可用/当前空闲/充足·偏紧·有缺口）、责任人、
待补授权与志愿者资质问题。`as_dict()` 可直接序列化展示。
