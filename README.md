# 非遗皮影剧场内容与互动资源排程

编排潮俗皮影演出、AI 动画、互动工作坊与非遗授权资源。

## 参与方与事实

主要参与方包括活动运营人员、皮影传承人、讲解与志愿者、参与游客、场地和物资管理员。领域资料记录以下已经确认的事实：

- 深圳海滨文化艺术区打造月下皮影剧场
- 活动包含主题展陈、皮影展演和互动工作坊
- 项目使用人工智能动画讲述中秋故事并推动非遗传承

## 业务约束

- 内容授权
- 演出版本
- 互动容量
- 教具库存
- 历史记录保留

`contracts/context.schema.json` 描述资料结构，`fixtures/context.json` 提供不含真实身份信息的示例，`src/shadow_play_context.py` 负责读取和校验这些资料。

## 文化活动后台

`src/shadow_play/` 是可运行的领域后台，把上述约束落成代码：

| 模块 | 职责 |
| --- | --- |
| `content.py` | 演绎内容、递增版本、传承人授权、AI 来源与适用范围、公开发布闸门 |
| `sessions.py` | 演出/展陈/工作坊场次，固定内容版本快照与责任人 |
| `resources.py` | 场地、按个体编号管理的教具库存、志愿者语言/技能要求 |
| `bookings.py` | 参与者预约、迟到判定、幂等签到凭证 |
| `office.py` | 总控 `BackOffice`：排程闸门、资源互斥重算、取消与完成、负责人总览 |
| `demo.py` | 一个活动日的演示数据（代号化虚构身份） |

核心保证：

- 公开演出只用**已确认**版本与**当日有效**授权；未登记/未获许可素材无法入库或被引用；
- AI 动画必须标明来源与适用范围，超范围使用被拒；
- 教具以个体编号跨时间重叠场次互斥，拆组、迟到、缺席、损坏、加场均按实际人数重算，**同一套教具不会双重分配**；
- 重复签到返回首次原凭证；取消只影响未发生场次，已完成演出与授权历史保留；
- 负责人总览同时呈现内容依据、资源水位、责任人、待补授权与志愿者资质问题。

## 开发命令

运行测试：

```bash
python3 -m unittest discover -s tests -v
```

编译检查：

```bash
python3 -m compileall -q src
```

查看演示场次总览：

```bash
python3 -m src.shadow_play.demo
```

三条命令只读取仓库内文件，不需要连接外部业务系统。
